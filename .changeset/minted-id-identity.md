A minted command ID is known by identity (#67 §3). The framework recorded that it minted an ID by a private symbol on the send options, and checked it with `in`, so a `Proxy` whose `has` trap answers true passed as minted: an application's own, possibly reused ID then predicted, and a first refusal counted as conclusive. The options the framework mints are now recorded in a module-private `WeakSet` and frozen. Not breaking.
